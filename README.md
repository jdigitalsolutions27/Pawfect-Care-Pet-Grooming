# Pawfect Care Pet Grooming

Premium pet grooming and pet care website built with React, TypeScript, Vite, Tailwind CSS, React Router, Framer Motion, React Hook Form, and Axios.

## Features

- Nine-page responsive website for a pet grooming brand
- Sticky navigation, mobile menu, floating booking/call buttons, scroll progress, loading animation, and back-to-top control
- Services, grooming packages, gallery filters, lightbox, testimonial carousel, blog preview, booking form, and contact form
- React Hook Form validation with Axios-based API-ready demo submission fallback
- SEO meta handling and semantic page structure
- Professional Unsplash photography throughout the site

## Setup

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
npm run preview
```
